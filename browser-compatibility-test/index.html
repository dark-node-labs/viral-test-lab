What is a browser compatibility test?

A browser compatibility test checks whether a browser exposes specific web APIs and platform features. This page checks media access, screen sharing, WebGL, WebGL 2, WebGPU, WebAssembly, local storage, service workers, and touch input.

Supported does not mean permitted

A browser can support an API while a permission, device, HTTPS requirement, extension, or operating system policy still prevents a particular tool from using it. Use the result as a starting point, then run the focused test.

Modernizr project reference

The feature-detection approach is informed by Modernizr, an MIT-licensed browser feature detection library. Quick Test Hub keeps this scan focused on current device and media capabilities and does not collect a fingerprint.

Privacy and browser detection

This page checks capability flags and temporary local APIs only. It does not create a visitor identifier, save a browser fingerprint, or upload your results. Camera, microphone, and screen content are not requested by this page.

Browser Compatibility Test FAQ

Why is WebGPU not detected?

WebGPU availability depends on browser version, operating system, graphics drivers, hardware, and browser settings. A browser update or enabled graphics acceleration may change the result.

Why is camera support detected but the webcam test fails?

API support only means the browser exposes the feature. The camera may be disconnected, blocked by permission, in use by another app, or unavailable to the current site context.
